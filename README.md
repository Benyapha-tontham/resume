## 🔧 How to Update

You can edit your portfolio directly in the repository files:

1. Edit `index.html` to update content (About, Skills, Works, Contact)
2. Edit `styles.css` to customize colors and styling
3. Commit and push changes to GitHub
4. The website will automatically update at: https://benyapha-tontham.github.io/resume/

### Updating colors in CSS:

Find the `:root` section in `styles.css` and modify:
```css
:root {
  --primary: #7c3aed;        /* Main color */
  --secondary: #06b6d4;      /* Accent color */
  --accent: #f59e0b;         /* Highlight color */
  /* ... more colors ... */
}
```

## 🚀 Local Development

1. Clone the repository
2. Open `index.html` in a browser, or
3. Use a local server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`
